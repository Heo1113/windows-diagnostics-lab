# 이벤트 분류 카탈로그

`wdl catalog`로 코드(EventCatalog)에서 생성한 문서입니다. 규칙은 항상 **공급자(Provider)**를 포함하며 이벤트 ID만으로 판단하지 않습니다.
ID가 비어 있는 행은 그 공급자의 기본 규칙입니다(특정 ID 규칙이 없을 때 적용). 카탈로그에 없는 공급자의 위험·오류 이벤트는 '기타 오류·경고'로 수집합니다.
